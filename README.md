# 🎟️ TicketZone – Event Ticket Booking System

TicketZone is a modern multi-step ticket booking application built using **HTML, CSS, and JavaScript**. The application provides users with a seamless event booking experience, allowing them to select events, choose seats, enter booking details, review their booking, and generate a digital ticket confirmation.

The project focuses on creating a realistic ticket booking workflow with an attractive dark-themed user interface and interactive user experience.

---

# 🚀 Features

### Event Selection

* Browse multiple available events.
* View event category, venue, date, and pricing.
* Select an event before proceeding to booking.

### Interactive Seat Selection

* Visual seat map layout.
* Available, selected, and occupied seats.
* Maximum seat selection validation.

### Booking Review
